# Hands-On Assignment — Scroll-Animated Website

## Project Overview

For this assignment, I created a cinematic scroll-animated automotive landing page inspired by premium product reveal websites from brands like Porsche, Tesla, and Apple.

The project focuses on using AI-assisted development workflows to generate, refine, and iterate on modern interactive UI experiences without manually building every component from scratch.

## Features

- Scroll-controlled frame sequence animation
- Sticky fullscreen cinematic canvas
- Hypercar assembly reveal interaction
- Premium dark automotive UI
- Smooth scrolling transitions
- AI-generated motion workflow
- Responsive landing page design

## What I Learned

Through this project, I learned how to:

- Describe UI ideas clearly to AI coding tools
- Generate and refine frontend experiences through prompting
- Build cinematic scroll interactions
- Use frame-sequence animation techniques
- Create premium visual storytelling experiences on the web
- Iterate on design through conversation-based development

I also understood how modern AI tools can significantly accelerate frontend development and creative experimentation.

## Tech Stack

- React
- Vite
- Tailwind CSS
- GSAP ScrollTrigger
- AI-generated image sequence workflow
