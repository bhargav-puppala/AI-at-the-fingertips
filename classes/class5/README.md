# Reflection Response — Class 5

## Question

> Think of a time you lost work — a document, a project, an assignment — because you had no backup. How would version control have helped in that situation? How does this change the way you think about saving your work going forward?

---

## My Response

I have experienced situations where I lost important work because I forgot to back it up or accidentally overwrote files while editing. It was frustrating because I had to spend extra time rebuilding things from scratch, and sometimes I could not recover the exact version I worked on before.

Version control would have helped a lot in those situations because it keeps track of every change made to a project. Instead of worrying about losing files, I could simply go back to an older version whenever something went wrong. It also makes working on projects much safer because even small mistakes can be reversed easily.

This changes the way I think about saving work because now I understand that saving a file once is not enough. Projects keep changing over time, especially in coding and development. Using Git and GitHub is like creating a timeline of your work, where every improvement and update is stored safely.

Going forward, I think version control is not just for professional developers — it is an essential habit for anyone building projects or learning technology.
